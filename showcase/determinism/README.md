# 동시성 · 순서 결정론 — 사례 코드

[`determinism_showcase.py`](determinism_showcase.py) 는 라이브 봇에서 실제로 푼 세 문제의 **발췌 재구성**입니다.
저장소 코드를 그대로 복사한 것이 아니라, 각 해법의 핵심 불변식만 남겨 표준 라이브러리만으로 단독 실행되게 다시 썼습니다.
파일 안 각 절 머리에 원 저장소의 위치와 시험 이름을 적어 두었습니다.

```bash
python determinism_showcase.py
```

| 절 | 불변식 | 자기검증 |
|---|---|---|
| 1 | 같은 입력 → 같은 포지션 (총액 상한 경합에서 처리 순서 고정) | 5! = 120 순열이 모두 같은 진입 · 탈락 목록, 대조군은 갈림 |
| 2 | 도착 순서와 무관한 상태 (뒤섞여 들어온 봉 = 정렬한 결과) | 시드 고정 200회 무작위 도착이 기준 구현과 정확히 동일 |
| 3 | 정리(GC)가 도는 스레드를 소유 스레드 하나로 고정 | 워커 대량 할당에도 종료자는 소유 스레드에서만, 침입자 회수 거부 |

추가 시험은 [`tests/test_determinism_showcase.py`](../../tests/test_determinism_showcase.py) 에 있습니다
(보유 종목 · 기존 명목 금액이 섞인 무작위 순열 불변성, 상한 미초과, 마감 경계 올림, 동률 규칙).

배경과 결정 이유는 [사례 모음](../../docs/case-studies/README.md) 의 1~3번을 보세요.
